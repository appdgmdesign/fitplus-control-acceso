# FIT&+ Control de acceso

Programa para el PC de la entrada del box (Windows 10 u 11).

## Descargar

**[Descargar FITplus-Control-de-acceso.exe](https://github.com/appdgmdesign/fitplus-control-acceso/releases/latest/download/FITplus-Control-de-acceso.exe)**

## Instalar

1. Abre el archivo descargado (en la carpeta **Descargas**).
2. Si Windows avisa con una ventana azul («Windows protegió su PC»): pulsa **Más información** y después **Ejecutar de todas formas**.
3. Se instala solo, sin pedir permisos, y deja el icono **FIT&+ Control de acceso** en el escritorio.

Las actualizaciones llegan solas: no hace falta volver a descargarlo.
